# 🛍️ Lojinha CRM — WhatsApp Cockpit & Kanban

Plataforma completa de gestão de vendas e CRM para WhatsApp com atendimento em tempo real (Cockpit Split), Kanban dinâmico, catálogo de produtos com fotos e vídeos, controle de instâncias Evolution GO e persistência no Supabase.

---

## 🚀 Tecnologias

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Supabase JS (Realtime Broadcast)
- **Backend:** Node.js, Express, TypeScript, Evolution GO API (WhatsApp), Supabase
- **Banco de Dados & Realtime:** Supabase (PostgreSQL) com WebSockets em tempo real (0ms latency, zero polling)
